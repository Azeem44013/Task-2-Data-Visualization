# Task 2 – Data Visualization and Storytelling

## 📌 Project Overview

This project focuses on creating a visual sales and profit analysis dashboard using the **Superstore dataset**.

The dashboard was created using **Power BI** to transform sales data into meaningful visualizations and business insights.

## 🎯 Objective

The main objective of this task is to:

- Create meaningful data visualizations
- Identify sales and profit trends
- Compare category and sub-category performance
- Analyze regional performance
- Present business insights through visual storytelling
- Create an interactive Power BI dashboard

## 🛠️ Tools Used

- Power BI Desktop
- Microsoft Excel / CSV
- Data Visualization
- Data Storytelling

## 📊 Dataset

**Dataset:** Superstore Dataset

The dataset contains sales-related information such as:

- Order ID
- Order Date
- Region
- Category
- Sub-Category
- Sales
- Profit
- Quantity
- Discount

## 📈 Dashboard Visualizations

The Power BI dashboard contains the following visualizations:

### 1. Total Sales
Displays the overall sales generated from the dataset.

### 2. Total Profit
Shows the total profit generated from sales.

### 3. Total Orders
Displays the number of orders in the dataset.

### 4. Monthly Sales Trend
A line chart showing how sales change across different months.

### 5. Sales by Category
Compares sales performance across:

- Technology
- Furniture
- Office Supplies

### 6. Sales by Region
Provides a comparison of sales performance across different regions.

### 7. Profit by Category
Shows the profit contribution of each product category.

### 8. Sales by Sub-Category
Provides a detailed comparison of sales across different product sub-categories.

## 🔎 Interactive Filters

The dashboard includes interactive filters for:

- Category
- Region
- Order Date

These filters allow users to explore the data based on specific business requirements.

## 💡 Key Business Insights

The dashboard helps identify:

- Overall sales and profit performance
- Monthly sales trends
- High-performing product categories
- Differences in regional sales
- Top-performing sub-categories
- Relationship between sales and profitability
